# 스마트팜 — 구글 시트 + Apps Script 만들기 (클릭 단위)

> 교실 환경 모니터링 때와 같은 방법이에요. 이름과 항목만 스마트팜용으로 바뀝니다.
> 처음이라면 4회차 자료도 참고 → [4회차 따라하기](https://github.com/ralralra/eps32/blob/main/esp32-class-projects/02_sessions/04_cloud_expansion/따라하기.md)

## 1. 시트 준비

1. [sheets.new](https://sheets.new) → 새 스프레드시트, 이름 `스마트팜`
2. **시트1** 탭 1행에 머리글 입력:

   | A | B | C | D |
   |---|---|---|---|
   | 시각 | 토양습도 | 온도 | 습도 |

3. 왼쪽 아래 **+** 로 새 탭 추가 → 이름을 **설정** 으로
4. **설정 탭 A1** = 명령 칸. 일단 `AUTO` 라고 적어 두세요.
   (앱이 여기에 `FAN_ON` 같은 명령을 쓰고, ESP32가 읽어 가요)
5. **설정 탭 B1** = 급수 알림 기준 토양습도(%). 일단 `30` 입력
   (토양습도가 이보다 낮으면 = 마르면, 앱에 "물 주세요!" 경고)

## 2. Apps Script 붙여넣기

1. 시트 메뉴 `확장 프로그램` → `Apps Script`
2. 편집기의 기존 코드 전부 지우고 → [`07_apps_script_smartfarm.gs`](../code/07_apps_script_smartfarm.gs) 내용 전체 복사 → 붙여넣기
3. 💾 저장 (Ctrl+S)

## 3. 웹앱으로 배포

1. 오른쪽 위 파란 **배포** → **새 배포**
2. ⚙(톱니) → **웹 앱** 선택
3. 설정:
   - 다음 사용자 인증: **나**
   - 액세스 권한: **모든 사용자** ← 꼭!
4. **배포** → 권한 요청이 뜨면: 계정 선택 → `고급` → `…(안전하지 않음)으로 이동` → 허용
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사 — **/exec로 끝나는지 확인!**

## 3-1. 코드를 고쳤다면? — 재배포는 "배포 관리"로!

Apps Script는 코드를 저장(Ctrl+S)해도 **/exec 주소에는 반영이 안 됩니다.**
주소는 "배포된 버전"을 계속 실행하거든요. 반영하는 방법이 두 가지인데:

- ✅ **배포 관리로 업데이트 (추천!)**: `배포` → **`배포 관리`** → 기존 배포 옆 **연필(✏️) 아이콘** → 버전을 **"새 버전"**으로 선택 → `배포`
  → **주소가 그대로 유지**돼요. 보드 코드의 URL, 앱의 URL 모두 안 바꿔도 됩니다.
- ⚠️ **새 배포**: `배포` → `새 배포`로 하면 **주소가 새로 발급**돼요. 그러면 보드 코드의 URL과 AI Studio 앱의 URL을 전부 바꿔야 해서 번거로워요.

정리하면:

| 바뀐 것 | 해야 할 일 |
|---|---|
| **.gs (Apps Script) 코드** | 저장 → `배포 관리` → ✏️ → **새 버전** → 배포 (주소 유지) |
| **.ino (보드) 코드** | 보드에 재업로드만 — Apps Script는 건드릴 필요 없음 |
| **앱 화면/기능** | AI Studio에서 수정 — 다른 건 건드릴 필요 없음 |

> 재배포 후에는 브라우저에서 `URL?mode=cmd`를 열어 바뀐 응답이 나오는지 확인하면 확실해요.

## 4. 브라우저로 먼저 테스트 (보드 없이!)

주소창에 직접 쳐 보세요 (URL 뒤에 붙이기):

| 테스트 | 주소 뒤에 붙일 것 | 기대 결과 |
|---|---|---|
| 기록 저장 | `?soil=45&temp=25.3&humi=60` | 시트1에 새 줄 + 응답 `AUTO,30` |
| 명령 읽기 | `?mode=cmd` | `AUTO,30` (설정!A1 명령, B1 기준값) |
| 명령 쓰기 | `?mode=set&cmd=FAN_ON` | 설정!A1이 `FAN_ON`으로 |
| 최신값 읽기 | `?mode=latest` | 마지막 줄 JSON |
| 기준값 바꾸기 | `?mode=limit&value=35` | 설정!B1이 `35`로 |
| 기준값 읽기 | `?mode=getlimit` | `35` |

여섯 개가 모두 되면 → 보드 코드([06_cloud_smartfarm](../code/06_cloud_smartfarm/06_cloud_smartfarm.ino))의 ★ 3줄만 바꿔 업로드하세요.

## 명령 규칙 (앱 ↔ 보드 약속)

| 설정!A1 값 | ESP32 동작 |
|---|---|
| `AUTO` | 자동 모드 — 더우면·습하면 팬, 추우면·과습이면 보온등 (기준은 코드의 강낭콩 발아 값) |
| `FAN_ON` / `FAN_OFF` | 쿨링팬 강제 켜기/끄기 (수동) |
| `LED_ON` / `LED_OFF` | 네오픽셀 따뜻한 빛 켜기/끄기 (수동) |

> ⏱ **버튼 반응 속도**: 앱 버튼 → 실제 동작까지 **3~6초**가 정상이에요.
> 앱이 시트에 명령을 쓰면(즉시), 보드가 3초마다 시트를 확인해서 실행하는 구조거든요 — 폴링의 특징!

> 💧 급수는 명령이 아니라 **알림**이에요 — 키트에 펌프가 없어서, 토양습도가 기준(B1) 아래로 내려가면
> 앱과 시리얼에 "물 주세요!"가 뜨고 사람이 직접 물을 줍니다. (펌프를 추가하면 명령으로 업그레이드!)
